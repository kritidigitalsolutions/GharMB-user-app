1. 🌟 What is the GharMB Mobile App?

GharMB is a dedicated real estate mobile platform designed specifically for the Mira-Bhayandar region. It solves the everyday challenges of finding, renting, buying, and selling residential and commercial properties by providing 100% verified listings, direct developer connections, token bookings, and automated site visit scheduling.

🏠 Residential 1BHK, 2BHK, 3BHK, Villas, PGs
🏢 Commercial Offices, Shops, Warehouses
🏗️ Builder Projects Upcoming towers, Floor plans
⚡ Quick Services Home Loans, Packers, Legal
💡 Why is this app special?
Unlike traditional broker-heavy apps, GharMB ensures that every property listed is verified, provides an integrated token booking engine to prevent fake reservations, and enables real-time site visit management between buyers and sellers.

2. 👥 The 4 Types of Users (Personas)

The app adapts seamlessly depending on who is using it:

1. Buyer / Tenant (Looking for Property)

Buyer / Tenant

Goal: Find a verified flat, shop, or office to rent or buy, schedule physical visits, and reserve the property using a token.

2. Property Owner / Seller (Listing Personal Property)

Property Owner

Goal: Post a personal flat or commercial space for sale/rent in 6 easy steps, review buyer visit requests, and approve token booking offers.

3. Real Estate Agent / Channel Partner

Real Estate Agent

Goal: Register with RERA/Agency credentials, post multiple client properties, manage bulk inquiries, and coordinate site visits.

4. Builder / Developer (Creating Mega Projects)

Builder / Developer

Goal: Register company profile, showcase new construction projects with tower unit configurations, master plans, amenities, and collect direct buyer inquiries.

3. 🗺️ Detailed Step-by-Step User Flows

User Flow A: Buyer / Tenant Journey

Flow: Buyer
  • 1
    Open App & Quick Login: Enter phone number, receive instant OTP, and reach the Home Feed.
  • 2
    Discover Properties: Browse the home feed, search by locality (e.g. Beverly Park, Silver Park), or tap "Search on Map" to find homes around GPS radius.
  • 3
    Filter & Shortlist: Filter by Rent/Buy, Price range, Carpet Area, BHK count. Tap the Heart Icon to save to Wishlist.
  • 4
    View Full Details: Inspect high-res photo gallery, carpet area, maintenance fee, amenities list, and seller verification badge.
  • 5
    Schedule a Site Visit: Choose a preferred date and morning/evening time slot. The owner receives an instant notification.
  • 6
    Book with Token: Reserve the property by placing a token request to lock the property before others buy it.

User Flow B: Property Owner / Seller Journey

Flow: Seller
  • 1
    Tap "+ List Property": Tap the central "+" button on the bottom navigation bar.
  • 2
    Step 1 - Listing Type: Select Residential (Rent/Sell/PG) or Commercial (Office/Shop).
  • 3
    Step 2 - Basic Details: Enter building name, locality, address, and city.
  • 4
    Step 3 - Specs & Amenities: Set BHK, Carpet Area (Sq.Ft), Floor No, Parking, Lift, Gym, Gas Pipeline.
  • 5
    Step 4 - Photos & Media: Upload clear room photos and property video.
  • 6
    Step 5 - Pricing & Review: Set expected rent/price, deposit amount, and submit for verification.
  • 7
    Manage Visits & Tokens: In My Dashboard, view incoming site visits (Accept/Reject) and token offers.

User Flow C: Real Estate Agent Journey

Flow: Agent
  • 1
    Register as Agent: Complete agent onboarding with RERA registration number and agency name.
  • 2
    Manage Multi-Inventory: Post and manage multiple client flats and commercial spaces under one unified profile.
  • 3
    Respond to Inquiries: Handle direct calls and WhatsApp leads from verified buyers.

User Flow D: Builder & Developer Journey

Flow: Developer
  • 1
    Developer Onboarding: Register company details, past experience, and corporate office address.
  • 2
    Add Mega Project: Create project listing with master plans, tower configurations (1/2/3 BHK), launch dates, and RERA approval numbers.
  • 3
    Direct Lead Generation & Reviews: Receive buyer inquiries directly and build public trust through customer reviews and ratings.

5. 🧩 Key Modules & Features Overview

🪙 1. Token Reservation Engine

High Security

Enables serious buyers to lock a property with a token. When a token is requested, the property moves into Reserved status, preventing conflicting bookings. The owner can inspect the buyer's profile and either Accept or Reject the token.

📅 2. Real-Time Site Visit Management

Zero Friction

Replaces chaotic phone calls with a structured appointment system. Buyers select a calendar day and time window. Owners receive push notifications and can approve or suggest alternate timings.

🛠️ 3. Financial & Area Calculation Tools

Utility Tools

Loan Calculator: Interactive sliders to calculate monthly EMI based on loan amount, interest rate, and tenure.
Unit Converter: Instant conversion between Square Feet, Square Meters, Guntha, Gaj, Acres, and Hectares.

6. 💻 Technical Blueprint for Developers

A. Folder Architecture

The app follows a Feature-First Architecture. Everything related to a feature lives in its own folder:

lib/
├── core/              -- App-wide URLs, Dio NetworkApiService, LocalStorage, Themes
├── features/
│   ├── auth/         -- Login, OTP, Onboarding, Role selection
│   ├── property/     -- Residential listings, Property details, 6-step Add Property form
│   ├── commercial/   -- Office & shop listings, Commercial filters & details
│   ├── developer/    -- Builder project creation, Developer profiles & reviews
│   ├── profile/      -- User dashboard, Site visits, Token requests, Calculators
│   └── home/         -- Banners, Map search, Notifications, Wishlist
├── routes/            -- GoRouter configuration & route name constants
└── shared/            -- Reusable Buttons, TextFields, Snackbars, BottomNavBar

B. State Management with Riverpod

State is cleanly separated from UI widgets using Riverpod StateNotifiers:

  • 1
    Immutable State: Every provider has a dedicated state class (e.g. holding isLoading, errorMessage, and dataList).
  • 2
    Zero Business Logic in UI: UI widgets only call provider methods like ref.read(provider.notifier).submitForm() and listen with ref.watch(...).

C. Session & Auto Token Refresh

When the app opens, SplashScreen reads the saved token from LocalStorageService. If expired, it calls POST /user/auth/refresh-token. If valid, the user goes straight to MyHomePage without having to log in again!

🚀 How to add a new screen in 5 minutes:
1. Create model in features/[name]/models/
2. Add API endpoint in core/constants/app_urls.dart
3. Create repo & provider in features/[name]/
4. Create UI screen using ConsumerWidget
5. Register the route in routes/app_routes.dart
